### Dag 2 - 4 februari 

#### Wat heb ik vandaag gedaan?
Ik ben begonnen met 2 workshops van Justus. Workshop 1 | Directus → FETCH → JSON → HTML. Hier hebben we data opgehaald uit een API met de Fetch methode. Vervolgens ben ik ook naar Workshop 2 | Endpoints en/of Custom JSON gegaan. Hier heb ik geleerd dat maar elke functie een functionaliteit mag hebben en heb ik geleerd hoe je kan parsen met JSON. 

In de middag moest ik ergens heen maar zelf ben ik daarna thuis begonnen met een opzet maken van mijn grid met afbeeldingen. Ik heb css grid lanes gebruikt om de afbeeldingen uit te lijnen. Ik ben begonnen met mobile-first grid tijdens het ontwerpen hiervan. 

#### Hoeveel tijd heeft me dat gekost?
Workshops 2 uur en zelfstandig werken 3 uur.

#### Wat heb ik geleerd?
Ik heb geleerd hoe ik data kan ophalen uit een API met fetch en hoe je het kan toe passen om ontwerp te maken die je op meerdere manieren kan verwerken in je site. 

#### Wat ga ik morgen doen?
Ik ga een workshop volgen over theming en verder met de afbeeldingen uitzoeken voor op mijn site.
